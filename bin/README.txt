



Pré-requis : Node.js installé





1. Lancer le backend :




cd C:\Users\User\Desktop\2526_INFOB318_APM\projet\backend

npm install   (si pas déjà fait)

node server.js   (écoute sur http://localhost:5000)



---------------------------------------------------------------------------




2. Lancer le frontend :


cd C:\Users\User\Desktop\2526_INFOB318_APM\bin\build
npx serve   (ex. http://localhost:3000)





----------------------------------------------------------------------------


Notes :

- Le frontend communique avec le backend sur le port 5000
- Si le port 3000 est occupé, "serve" choisira un autre port automatiquement
- Ne pas fermer le terminal du backend pendant l'utilisation
